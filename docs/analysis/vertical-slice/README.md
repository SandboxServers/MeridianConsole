# Campaign: vertical-slice

**Goal (D-01, owner-approved MVP):** login → Panel → enroll a real Windows agent → create/start/stop one Minecraft server on that node → live console tail. Deployable with `deploy/compose/docker-compose.services.yml` plus the Windows agent. No billing, no Linux agent, Minecraft only (hardcoded, no engine abstraction).

**Base:** `origin/main` at `2c4c19c` (PR #187 "Sprint 1" merged 2026-10-26 20:46Z, D-04). The ledger branch was cut from `9a1a3a6`; it adds only new files, so ops rebases it onto `origin/main` before its PR.

**Process:** `.claude/skills/campaign-packet/SKILL.md`. Contract and packets: [work-packets.md](work-packets.md). Resume card: [RESUME.md](RESUME.md).
