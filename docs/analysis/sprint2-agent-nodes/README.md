# Campaign: sprint2-agent-nodes

Sprint 2 connects the Windows agent to Nodes. Sprint 1 (PR #187, merged at `2d8e4d0`) made enrollment work end to end. This campaign adds the rest:

1. A SignalR hub at `/hubs/agent` in Nodes, authenticated by the agent's client certificate and routed through the Gateway. Its typed interfaces live in `Dhadgar.Contracts`.
2. Heartbeats sent over the hub, feeding Nodes' existing health tracking (`IHeartbeatService`).
3. An agent startup service that enrolls if needed, saves the node ID and connects. This fixes #101.
4. Certificate renewal on the same agent-held-key approach as enrollment: the agent sends a public key and Nodes signs it.

Out of scope:

- Command handlers and command signing (#94, #118). They belong to the next campaign.
- PR #88 (Servers/Console/Mods), which is parked.
- The Linux agent. `Dhadgar.Agent.Linux/Program.cs` is still a stub.

Plan of record: [work-packets.md](work-packets.md). Resume card: [RESUME.md](RESUME.md).

| D-S212 | **Revocation grace on renewal: (B), owner ruling 2026-10-27, as a short fixed window.** On renewal the presented certificate is marked `IsRevoked=true` with a new nullable column `AgentCertificate.GraceUntil = now + Mtls:RenewalGraceMinutes` (default `AgentCertificateRenewalPolicy.DefaultGraceMinutes` = 60, range 0-1440; 0 means immediate revoke).
