## Fix notes

N1. src/Agents/Dhadgar.Agent.Core/Health/HeartbeatPayloadMapper.cs:30-34 and :41 — The Nodes validator `AgentHeartbeatValidator` (`src/Dhadgar.Nodes/Hubs/AgentHeartbeatValidator.cs:31,47`) rejects any `AgentVersion` or `HealthIssues` entry that contains a `char.IsControl` character (added in P04 fix-1, S-N2). The mapper only truncates, so a warning such as an exception message with a newline or tab makes the whole heartbeat come back `invalid_heartbeat`. The mapper exists to stop exactly that. — Change `Truncate` so it first replaces control characters, and keep both call sites. Replace the method at line 61-62 with `private static string Truncate(string value, int maxLength) { var cleaned = string.Create(value.Length, value, static (span, src) => { for (var i = 0; i < src.Length; i++) { span[i] = char.IsControl(src[i]) ? ' ' : src[i]; } }); return cleaned.Length <= maxLength ? cleaned : cleaned[..maxLength]; }`. Rename it `Sanitize` if you prefer, but then update lines 33 and 41. Add two tests to `HeartbeatPayloadMapperTests.cs`. `ToContract_ControlCharactersInWarning_AreReplaced`: a warning of `"line1\r\nline2\0"` must give `HealthIssues[0]` equal to `"line1  line2 "`. `ToContract_ControlCharactersInVersion_AreReplaced`: an `AgentVersion` of `"1.0\n2"` must give `"1.0 2"`. Then assert `AgentHeartbeatValidator`-style validity: `Assert.DoesNotContain(heartbeat.HealthIssues!.Single(), char.IsControl)`. — verify: both new tests fail on the old `Truncate` and pass on the new one. `dotnet test tests/Dhadgar.Agent.Core.Tests` is green.
