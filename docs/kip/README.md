# KiP Edition (Self-Hosted)

**Status: not yet written.** The KiP (single-tenant, self-hosted) edition is a stated
product goal (see root `README.md` FAQ and ADR-0006), but no self-hosting documentation
exists yet and no KiP-specific configuration has been built.

Until this is real, the closest thing to a self-hosted deployment is
`deploy/compose/docker-compose.services.yml`, which runs the full stack locally.

This page intentionally says so rather than pretending otherwise — see
`docs/PROJECT-STATE.md` for the overall roadmap.
